# Module 13: Exercises

## Exercise 1: Complete Auth System

**Difficulty:** Intermediate | **Time:** 180-240 min

Build full authentication with email verification, password reset, and social login.

**Requirements:**

- Email/password registration with verification
- Password reset workflow
- Google and GitHub OAuth
- Session management
- Profile settings page

---

## Exercise 2: Multi-Tenant SaaS

**Difficulty:** Advanced | **Time:** 240+ min

Create multi-tenant platform with organizations and team collaboration.

**Requirements:**

- Organization creation and management
- Member invitations via email
- Role-based permissions (owner, admin, member)
- Organization switching
- Team dashboard

---

## Exercise 3: Enterprise Admin Panel

**Difficulty:** Advanced | **Time:** 180+ min

Build admin panel with user management and analytics.

**Requirements:**

- User CRUD operations
- User search and filtering
- Ban/unban functionality
- Audit log
- Analytics dashboard
