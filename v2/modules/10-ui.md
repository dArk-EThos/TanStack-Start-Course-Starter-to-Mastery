# Module 10 — UI with shadcn

**Pulse files:** `src/components/ui/*`, `src/styles/app.css`, `components.json`

shadcn/ui is not an npm component library. The CLI copies source into your repo. On TanStack Start:

```bash
pnpm dlx shadcn@latest init -t start -d --base radix
pnpm dlx shadcn@latest add button card input label textarea badge
```

Pulse already contains a New York–style subset so the app runs without the CLI. Use the CLI when you want Dialog, Sheet, Table, Dropdown Menu, and the rest.

## Tailwind v4

```css
@import "tailwindcss";

@theme inline {
  --color-background: var(--background);
  --color-primary: var(--primary);
  --radius-lg: var(--radius);
}
```

There is no `tailwind.config.ts` unless you add one. The Vite plugin is `@tailwindcss/vite`.

Set `"rsc": false` in `components.json`. Start is not Next.js App Router.

## Composition

Build product screens from tokens (`bg-background`, `text-muted-foreground`, `border-border`) and primitives:

| Screen | Pieces |
| --- | --- |
| Auth | `Card` + `Input` + `Label` + `Button` + `Alert` |
| Dashboard | summary `Card`s + `Badge` |
| CRUD list | `Card` / `Table` + row actions |
| Filters | URL search + `Button`s + `Input` |

Do not invent a second button style. Extend `buttonVariants` if you need a new variant.

## Dark mode

Pulse sets `className="dark"` on `<html>` for a developer-tool default. For a toggle, store the preference in a cookie and read it in the root `beforeLoad` so SSR and client match.
