# Module 8: Exercises

## Exercise 1: Real-Time Chat Application

**Difficulty**: Intermediate-Advanced | **Time**: 120-150 min

Build a complete chat application with rooms, typing indicators, online presence, and message history.

**Skills**: WebSockets, Socket.IO, real-time state management, Prisma integration

## Exercise 2: Background Job System

**Difficulty**: Advanced | **Time**: 150-180 min

Create a background job processing system with Bull queue, job scheduling, retry logic, and monitoring dashboard.

**Skills**: Job queues, worker threads, async processing, Redis

---

## Exercise 3: Admin Dashboard with Analytics

**Difficulty**: Advanced | **Time**: 180+ min

Build comprehensive admin dashboard with real-time analytics, complex data aggregations, and interactive charts.

**Skills**: Complex queries, data aggregation, real-time updates, performance optimization
