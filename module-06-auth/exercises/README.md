# Module 6: Exercises

## Exercise 1: Complete Auth System

**Difficulty**: Intermediate | **Time**: 120-150 min

Build complete authentication with registration, login, logout, and password reset email flow.

**Skills**: Session management, email sending, token generation

---

## Exercise 2: Multi-Tenant SaaS

**Difficulty**: Advanced | **Time**: 180+ min

Team-based access control with invitations, roles (owner, admin, member), and resource isolation.

**Skills**: RBAC, multi-tenancy, complex permissions

---

## Exercise 3: OAuth Integration

**Difficulty**: Advanced | **Time**: 150+ min

Implement OAuth 2.0 with Google and GitHub providers, account linking, and profile sync.

**Skills**: OAuth flows, third-party integration, account management
