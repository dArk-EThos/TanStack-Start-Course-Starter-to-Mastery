# Module 14: Kinde Auth Exercises

## Exercise 1: Complete Authentication Flow

**Difficulty:** Beginner-Intermediate | **Time:** 90-120 min

Build complete auth with email/password, social login, and protected routes.

**Requirements:**

- Login/Register pages
- Google and GitHub OAuth
- Protected dashboard
- User profile page
- Logout functionality

**Skills:** Kinde SDK, authentication flows, protected routes

---

## Exercise 2: Multi-Tenant SaaS with Organizations

**Difficulty:** Intermediate-Advanced | **Time:** 150-180 min

Create multi-tenant app with Kinde's organization features.

**Requirements:**

- Organization creation
- Member invitations
- Organization switching UI
- Role-based dashboard views
- Organization settings page

**Skills:** Organizations, member management, context switching

---

## Exercise 3: RBAC Admin Panel

**Difficulty:** Advanced | **Time:** 120-150 min

Build admin panel with Kinde's Management API.

**Requirements:**

- User management (list, search, edit)
- Organization management
- Role assignment interface
- Permission management
- Feature flag controls
- Analytics dashboard

**Skills:** Management API, RBAC, feature flags

## Bonus Challenge: Feature Flag System

Implement feature flag-based feature rollout.
