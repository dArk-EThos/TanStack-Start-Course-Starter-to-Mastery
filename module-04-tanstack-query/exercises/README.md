# Module 4: Exercises

## Overview

Practice TanStack Query patterns with progressive exercises that build real-world features.

## Exercise 1: Social Feed with Real-Time Updates ⭐

**Difficulty**: Intermediate | **Time**: 90-120 min

Build a social media feed with automatic updates and optimistic UI.

**Features:**

- Infinite scroll feed
- Like/unlike posts (optimistic)
- Create new posts
- Auto-refresh on window focus
- Background updates every 30s

**Skills:** useInfiniteQuery, optimistic updates, cache invalidation

---

## Exercise 2: Product Catalog with Filters 🛍️

**Difficulty**: Intermediate-Advanced | **Time**: 120-150 min

Create a product catalog with advanced filtering and caching.

**Features:**

- Paginated product list
- Multiple filters (category, price, rating)
- Search functionality
- Product detail prefetching on hover
- Shopping cart with optimistic updates

**Skills:** Pagination, dependent queries, prefetching, complex cache management

---

## Exercise 3: Dashboard with Multiple Data Sources 📊

**Difficulty**: Advanced | **Time**: 150+ min

Build a complex dashboard fetching from multiple endpoints.

**Features:**

- Parallel data fetching (stats, charts, notifications)
- Real-time updates for critical metrics
- Error boundaries for individual widgets
- Retry logic with exponential backoff
- Global loading indicator

**Skills:** Parallel queries, error handling, advanced configuration
