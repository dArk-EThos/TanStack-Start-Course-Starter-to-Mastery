# Module 7: Exercises

## Exercise 1: Logging Middleware System

**Difficulty**: Beginner-Intermediate | **Time**: 60-90 min

Build comprehensive logging middleware with request/response tracking, performance monitoring, and error logging.

**Skills**: Request middleware, performance tracking, log formatting

## Exercise 2: Rate Limiting & Throttling

**Difficulty**: Intermediate-Advanced | **Time**: 90-120 min

Implement sophisticated rate limiting with multiple strategies (IP-based, user-based, endpoint-specific) and Redis backing.

**Skills**: Rate limiting algorithms, distributed systems, caching

---

## Exercise 3: Multi-Tenant Context System

**Difficulty**: Advanced | **Time**: 120+ min

Create middleware for multi-tenant SaaS with tenant isolation, context propagation, and database routing.

**Skills**: Multi-tenancy, context management, advanced middleware patterns
