# Module 9: Exercises

## Exercise 1: Component Library

**Difficulty**: Beginner-Intermediate | **Time**: 90-120 min

Build a reusable component system with custom themes, variants, and comprehensive Storybook documentation.

**Skills**: Component design, theming, documentation

---

## Exercise 2: Admin Dashboard UI

**Difficulty**: Intermediate-Advanced | **Time**: 150-180 min

Create a complete admin dashboard with data tables, charts, forms, and responsive layout using all ShadCN components.

**Skills**: Complex layouts, data visualization, responsive design

---

## Exercise 3: E-Commerce Product Page

**Difficulty**: Advanced | **Time**: 120+ min

Build a sophisticated product page with image gallery, variant selection, reviews, and add-to-cart functionality.

**Skills**: Advanced UI patterns, state management, user interactions
