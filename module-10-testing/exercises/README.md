# Module 10: Exercises

## Exercise 1: Complete Test Suite for Task Manager

**Difficulty**: Intermediate | **Time**: 120-150 min

Build comprehensive tests for task manager API: unit tests for server functions, integration tests for routes, and E2E tests for user flows.

**Skills**: Unit testing, mocking, integration testing, E2E testing

---

## Exercise 2: E2E User Flow Testing

**Difficulty**: Intermediate-Advanced | **Time**: 90-120 min

Create E2E tests for complete user journeys: registration → login → create content → edit → delete → logout.

**Skills**: Playwright, user flow testing, assertions

---

## Exercise 3: CI/CD Pipeline with Automated Tests

**Difficulty**: Advanced | **Time**: 120+ min

Set up GitHub Actions pipeline with parallel test execution, coverage reports, and deployment gates.

**Skills**: GitHub Actions, CI/CD, test automation, deployment
